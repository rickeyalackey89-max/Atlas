# Atlas Demon Specialist Product Names

Status: **CROSS-SPORT PRODUCT NAMING / CONTINUITY CONTRACT — USER/CHAT STRATEGIC AUTHORITY**

This file binds the product names used by Atlas for the shared Demon-tier / aggressive-alt-line specialist concept governed by `docs/coordination/ATLAS_DEMON_SPECIALIST_PRODUCT_DOCTRINE.md`.

The underlying product contract is the same across sports: sparse single-leg flex/add-on Demon picks, precision-first, abstention-friendly, normally about 0-3-ish fires per run/slate, and only emitted when a narrow current signal genuinely qualifies.

## Bound names

- WNBA: **FromDeep**
- NBA: **FromDeep**
- CBB: **FromDeep**
- MLB: **BigSwings**
- NFL: **HailMarys**
- CFB: same Demon-specialist product contract; sport-specific display name remains unbound here until the user names it explicitly.

These are product names, not different statistical philosophies. Chat, Prime, and Codex must not reinterpret BigSwings, HailMarys, or FromDeep as broad pick families merely because the sport or label changes.

## Shared semantics

Every named specialist above means:

> Atlas's narrowest, strongest, highest-conviction aggressive-line single-leg opportunities for the current run, with honest abstention when no specialist-grade signal exists.

They are optional flex/add-on single-leg surfaces beside the sport's core multi-leg Builder families. They do not themselves construct the core multi-leg slips unless a separate sport-specific product contract explicitly changes that behavior.

Future sport/model work should bind both this naming contract and `ATLAS_DEMON_SPECIALIST_PRODUCT_DOCTRINE.md` rather than rediscovering the concept.
